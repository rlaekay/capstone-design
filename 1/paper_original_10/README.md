# 원 논문 기록 그대로 재생하는 10개

두 동작 × 다섯 하중 조건 각각의 train/001.csv 하나씩을 선택했습니다.
총 10개, 107.056499초. source.csv는 공개 CSV와 바이트 단위로 동일합니다.
기본 재생은 pos1~pos6 실측 관절각과 원래 timestamp 간격을 사용합니다.
시간 원점만 첫 timestamp를 빼서 0으로 맞췄습니다. 그리퍼도 원본 그대로 움직입니다.
원본을 느리게/빠르게 늘리거나 평활화하거나 안전 경로로 변형하지 않았습니다.
화면 프레임 사이에는 기록 샘플을 선형 보간합니다.

프로젝트 루트에서:
```bash
MUJOCO_GL=glfw .venv/bin/python scripts/view_original_paper.py --auto
```
원본 목표 명령을 보려면 --signal commanded; 기본은 measured입니다.
현재 책상/클램프/드론 모델 위에서 비교하려면 --scene bench를 추가하세요.
N/P: 다음/이전, Space: 정지, R: 재시작, C: 충돌 형상. --index 8은 400g 옮기기 기록입니다.

이 뷰어는 기록된 관절각을 모델에 적용하는 기구학 재생입니다. PD 추종 물리 시뮬레이션이나 충돌 회피 궤적이 아닙니다.
bench 모델로 샘플별 검사한 결과 400g pick_and_place 기록(motion_008)은 wrist_flex가 모델 관절 상한/여유 한계를 벗어나는 샘플 35개를 포함합니다.
원본 실측 최대 1.68625657 rad, 모델 상한 약 1.65806273 rad. 원본 충실성을 위해 자르거나 변경하지 않았습니다.
그 외 9개는 측정 샘플 수준 검사를 통과했지만 연속 경로/동적 추종/실기 실행 안전을 인증한 것은 아닙니다.
하중 물체 자체의 외형/질량은 뷰어에 추가하지 않았습니다.
